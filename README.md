## Overview

Sheath is a launch layer for Solana tokens. Commitments rest off-ledger while a round gathers, the token comes into existence once the round completes, and qualified participants collect their share. Every arrival pays the same amount per slice, and a uniqueness check keeps one human to one capped slot.

## Features

- Equal price per slice for the first arrival and the last
- One verified human, one capped slot per token
- Private verification: a verdict only, never a face, surname or document
- Live Solana market board with ticker, movers and per-token address copy
- A single register holds every external fact; anything unstated renders inert as "pending"
